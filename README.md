# The 9th River

*A creative coding laboratory exploring the language of resonance.*

---

## What is this?

The 9th River is a long-term exploration of generative systems.

It is a place to experiment with the rules behind nature, music, and visual art.

---

## Current Direction

For now, every sketch follows a very simple pipeline:

```text
Piano
    ↓
MIDI
    ↓
JSON Note Events
    ↓
Resonance Elements are born
    ↓
Natural Algorithms
(Perlin Noise, Flow Fields, Boids, ...)
    ↓
20–40 second audio visual artwork
```

Each note gives birth to a small group of living particles.
